breakoutgraphics_extension.py — collision detection & power-ups

def check_collisions(self):
    # Check the four corners of the ball
    vertex_1 = self._window.get_object_at(self._ball.x, self._ball.y)
    vertex_2 = self._window.get_object_at(self._ball.x + BALL_RADIUS * 2, self._ball.y)
    vertex_3 = self._window.get_object_at(self._ball.x, self._ball.y + BALL_RADIUS * 2)
    vertex_4 = self._window.get_object_at(self._ball.x + BALL_RADIUS * 2,
                                          self._ball.y + BALL_RADIUS * 2)
    for vertex in (vertex_1, vertex_2, vertex_3, vertex_4):
        if vertex not in (None, self._board, self._item):
            if vertex is self._paddle:
                if self.__dy > 0:  # Bounce only when the ball is falling
                    self.__dy = self.__dy * -1
            else:
                self.__dy = self.__dy * -1
                self._window.remove(vertex)
                self.update_score()
                self.random_item()
            break

def random_item(self):
    if self._item is not None:
        return
    chance = random.random()
    if chance < 0.15:
        self.create_item(WIN_COLOR, 2)      # bonus: paddle x2
    elif chance < 0.3:
        self.create_item(LOSE_COLOR, 0.5)   # penalty: paddle x0.5

Challenge

Build a complete game loop: mouse-controlled paddle, bouncing ball, 100 bricks, three lives, and win / lose screens.

Approach

Separated game logic from a BreakoutGraphics class and exposed state through properties and setters. Collisions are detected by checking the ball's four corners.

Extension

Random power-ups: 15% bonus (paddle ×2), 15% penalty (paddle ×0.5), with the width bounded between 5% and 80% of the window.

What I learned

Encapsulation, event-driven programming, and designing rules that keep a game fair and fun.

babynames.py — building the data structure & search

def add_data_for_name(name_data, year, rank, name):
    if name not in name_data:
        name_data[name] = {year: rank}
    elif year not in name_data[name]:
        name_data[name][year] = rank
    else:
        # Same name in both lists: keep the better (smaller) rank
        pre_rank = name_data[name][year]
        name_data[name][year] = str(min(int(pre_rank), int(rank)))


def search_names(name_data, target):
    matching_names = []
    t = target.lower()
    for name in name_data:
        if t in name.lower():
            matching_names.append(name)
    return matching_names

Challenge

Turn 13 raw text files (1900–2020) into an app where anyone can search a name and see its popularity trend.

Data pipeline

Parsed each file into a nested dictionary {name: {year: rank}}, keeping the best rank when a name appears in both the male and female lists.

Visualization

Mapped years and ranks to canvas coordinates, drew trend lines in rotating colors, and marked missing data with “*”.

What I learned

Cleaning real-world data, choosing the right data structure, and presenting data so people can read it at a glance.
